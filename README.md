# Snake Game
Author: Andrew Kwolek

Classic Snake Game I made as a side project to get back up to speed with Python before beginning my Master's degree!

## Quickstart
1. Clone repo.
2. Run `python3 main.py`

## Controls
- WASD: up, left, down, right
